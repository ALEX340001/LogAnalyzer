LogAnalyzer

Консольная утилита для поиска ключевых слов в лог-файлах. Поддерживает рекурсивный обход папок, гибкую настройку расширений и экспорт результатов в нескольких форматах.

Готов к использованию Скачайте последнюю версию из раздела Releases или соберите из исходников.

Ключевые возможности

  • Асинхронное чтение файлов — потоковая обработка без перегрузки памяти
  • Рекурсивный обход папок с фильтром по расширениям
  • Гибкая настройка ключевых слов и путей через JSON-конфиг
  • Два режима запуска: CLI и интерактивное меню
  • Экспорт результатов в txt, json, xml и wordgroup
  • Встроенное логирование с маскированием данных

Быстрый старт

# Поиск ошибок в одном файле
LogAnalyzer.exe -p "C:\Logs\app.log" -k "ERROR,Exception,Timeout"

# Анализ папки с сохранением JSON-отчёта
LogAnalyzer.exe -p "C:\Logs\" -o "report.json" -f json -r

# Использование пользовательского конфига
LogAnalyzer.exe -c "my_config.json" -p "C:\Logs\"
Важно Для чтения защищённых логов (например, из системы) может потребоваться запуск от имени администратора.
