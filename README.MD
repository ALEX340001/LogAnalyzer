LogAnalyzer — это легковесное консольное приложение для быстрого поиска ключевых слов в лог-файлах. Поддерживает рекурсивный обход папок, гибкую настройку расширений, несколько форматов вывода и два режима работы: интерактивное меню и командная строка.

Это мой рабочий MVP — я создал его, чтобы упростить анализ логов в повседневных задачах, и делюсь им, потому что он может быть полезен и другим.

Основные возможности
Асинхронное чтение файлов — потоковая обработка, память не перегружается.

Рекурсивный обход папок — анализирует все файлы с нужными расширениями.

Гибкие настройки — можно менять расширения, пути, ключевые слова.

Два режима запуска:

Интерактивное меню — для ручной работы и настройки.

CLI-режим — для автоматизации и CI/CD.

Несколько форматов отчётов: txt, json, xml, wordgroup.

Конфигурация через JSON — настройки сохраняются и переиспользуются.

Быстрый старт
Запуск через командную строку
bash
# Анализ одного файла с выводом в консоль
LogAnalyzer.exe -p "C:\Logs\app.log" -k "ERROR,Exception,Timeout"

# Анализ всей папки с сохранением отчёта в JSON
LogAnalyzer.exe -p "C:\Logs\" -o "report.json" -f json -r

# Использование пользовательского файла конфигурации
LogAnalyzer.exe -c "my_config.json" -p "C:\Logs\"
Интерактивный режим
Если запустить приложение без аргументов, откроется меню, где можно:

Добавить или удалить пути к файлам/папкам.

Настроить список расширений для поиска.

Добавить или удалить ключевые слова.

Запустить анализ и сохранить отчёт.

Состояние проекта
Статус: рабочий прототип (MVP)

Проект полностью функционален и стабильно работает на моих тестовых наборах. Однако, поскольку это мой личный учебно-боевой инструмент, в коде есть известные ограничения:

Архитектура ещё не приведена к идеальным паттернам SOLID.

Нет модульных тестов (пока что).

Некоторые части требуют рефакторинга (например, меню и обработка ошибок).

Я выложил его в открытый доступ, чтобы показать направление мысли и получить обратную связь. Если вам что-то непонятно или вы нашли баг — создавайте Issue, я постараюсь помочь. Звёзды и форки тоже приветствуются.

Технологии
.NET 9 — целевой фреймворк.

CommandLineParser — разбор аргументов командной строки.

Асинхронное программирование — async/await, IAsyncEnumerable.

JSON — хранение настроек и экспорт отчётов.
