Конфигурационный файл setting.json

Все настройки хранятся в файле setting.json, который по умолчанию находится в Documents\MyAnalyzerLog\SettingJson\.

Структура JSON

ПолеТипОбязательноеОписание
Keywordsмассив строкСписок ключевых слов для поиска (регистронезависимо)
IncludeSubdirectoriesbooleanВключить рекурсивный обход подпапок (по умолчанию true)
MaxParallelFilesчислоМаксимальное количество одновременно обрабатываемых файлов (по умолчанию 5)
LogPathsмассив строкСписок путей к файлам/папкам для анализа
DefaultSavePathстрокаКорневая папка для сохранения настроек и заметок
OutputFilePathстрокаПуть для сохранения результатов анализа

Пример файла

{
  "Keywords": ["ERROR", "Exception", "Timeout"],
  "IncludeSubdirectories": true,
  "MaxParallelFiles": 5,
  "LogPaths": ["C:\\Logs\\app.log", "C:\\Logs\\system"],
  "DefaultSavePath": "C:\\Users\\User\\Documents\\MyAnalyzerLog",
  "OutputFilePath": "C:\\Reports\\result.txt"
}
Приоритет параметров
Параметры командной строки имеют приоритет над настройками из JSON-файла. Если указан -c, загружается указанный конфиг, иначе используется глобальный.
