Система логирования

В проекте используется встроенная система логирования через класс Get_log.

Особенности

  • Логи пишутся в папку Documents\MyLogger_Program_log\.
  • Ежедневно создаётся новый файл с именем YYYY-MM-DD_log.txt.
  • Потокобезопасность обеспечивается через SemaphoreSlim.
  • При ошибках записи сообщение выводится в консоль.

Использование

await Get_log.LoggerAsync("Приложение запущено");

Отключение логирования

При запуске с флагом -d или --disable-logging все вызовы Get_log игнорируются.
