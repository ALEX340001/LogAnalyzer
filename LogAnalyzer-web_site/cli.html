Интерфейс командной строки (CLI)

Все параметры командной строки переопределяют соответствующие настройки из JSON-файла.

Синтаксис

LogAnalyzer.exe [options]

Параметры

Короткий ключДлинный ключТипОписание
-p--pathстрокаПуть к лог-файлу или папке с логами
-k--keywordsстрокаКлючевые слова через запятую
-o--outputстрокаПуть для сохранения отчёта
-f--formatстрокаФормат отчёта: txt, json, xml, wordgroup
-r--final-report—Вывод итоговой статистики в консоль
-a--all-lines—Вывод каждой найденной строки
-s--show-consolebooleanВывод лога в консоль (по умолчанию true)
-d--disable-logging—Отключить встроенное логирование
-c--configстрокаПуть к пользовательскому JSON-конфигу

Примеры

# Базовый запуск с глобальным конфигом
LogAnalyzer.exe

# Анализ файла с ключевыми словами
LogAnalyzer.exe -p "C:\Logs\app.log" -k "ERROR,Exception"

# Анализ папки, сохранение JSON, вывод итогового отчёта
LogAnalyzer.exe -p "C:\Logs\" -o "report.json" -f json -r

# Отключение консольного вывода и логирования
LogAnalyzer.exe -p "C:\Logs\" -s false -d
