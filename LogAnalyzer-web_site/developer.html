Архитектура и разработка

LogAnalyzer написан на C# (.NET 9) и состоит из четырёх основных слоёв.

Структура проекта

LogAnalyzer/
├── Core/                    # Основная логика
│   ├── Services/            # Оркестрация анализа (AnalysisOrchestrator)
│   └── MenuSettingsFormation/
│       ├── AsyncMainMethods/   # Чтение, анализ, запись (Reader/Analyzer/Writer)
│       └── IO_SettingValues/   # Работа с JSON и путями
├── Config/                  # Работа с конфигурацией (меню создания/редактирования)
├── Data/                    # Модели данных (LogAnalyzerSettings) и инициализатор
├── Utils_Helpers/           # Логирование, проверки ввода, хелперы меню
└── Program.cs               # Точка входа

Ключевые классы

КлассНазначение
ProgramТочка входа. Парсит аргументы, загружает конфиг, запускает оркестратор или интерактивное меню.
AnalysisOrchestratorУправляет процессом анализа: сбор файлов, запуск чтения, обработка и запись отчёта.
LogAnalyzerSettingsМодель настроек (Keywords, LogPaths, MaxParallelFiles и т.д.).
LoadAndSaveЗагрузка и сохранение JSON-конфигов.
WriterЗапись отчётов в разных форматах (txt, json, xml, wordgroup).
LogStreamProcessorОбработка потока строк: поиск ключевых слов, сбор статистики.
Get_logВстроенное логирование с использованием SemaphoreSlim для потокобезопасности.

Поток выполнения

  1. Загрузка настроек (глобальный или указанный через -c конфиг).
  2. Сбор списка файлов (рекурсивно, с фильтром по расширениям).
  3. Асинхронное чтение каждого файла построчно.
  4. Поиск ключевых слов, сбор статистики по файлам и словам.
  5. Формирование отчёта (консоль + файл в указанном формате).
